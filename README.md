
# 🍎 Ma Garderie - Application Mobile

Application mobile développée pour la gestion des menus d'une garderie d'enfants.

## 🚀 Technologies Utilisées
- **Framework :** Flutter
- **Version control :** Git & GitHub

## 📱 Fonctionnalités
- **Splash Screen :** Écran de démarrage avec transition automatique après 3 secondes.
- **Page Principale :** Barre d'application avec boutons de recherche et notifications, Drawer de navigation, et bouton flottant (FAB).
- **Gestion des Menus :** Affichage dynamique sous forme de liste (ListView) des menus de la garderie.
- **Interactions :** Notifications interactives via SnackBar pour chaque action utilisateur.
